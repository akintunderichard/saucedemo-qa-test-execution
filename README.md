# SauceDemo QA Test Execution Project

## Project Overview
This project demonstrates manual functional testing of a demo e-commerce application. It covers test case design, test execution, result tracking and QA reporting.

## Application Under Test
SauceDemo Shopify Demo Store

## Testing Type
- Manual Functional Testing
- Positive Testing
- Negative Testing
- Regression Testing

## Testing Modules
1. User Registration
2. Login
3. Add to Cart
4. Remove from Cart
5. Checkout
6. Logout

## Project Deliverables
- Functional test cases
- Positive and negative test scenarios
- Test execution results
- QA execution dashboard
- Pass rate and test status summary

## Tools Used
- Google Sheets
- Microsoft Excel
- Google Chrome

## Test Execution Summary
The project includes an execution dashboard that tracks:
- Total test cases
- Passed test cases
- Failed test cases
- Blocked test cases
- Not Run test cases
- Overall pass rate
